# Как выложить «Перемену» в интернет

Шпаргалка на одну страницу. Ничего устанавливать на компьютер не нужно —
всё делается в браузере. Подробности и обоснования — в `README.md`.

Всего три шага: база → таблицы → сайт.

---

## Шаг 1. Завести базу данных

1. Зайдите на [neon.tech](https://console.neon.tech) и создайте проект
   (бесплатного тарифа хватит с запасом).
2. Скопируйте **строку подключения** — она выглядит так:

   ```
   postgresql://neondb_owner:ПАРОЛЬ@ep-xxx-pooler.eu-central-1.aws.neon.tech/neondb?sslmode=require
   ```

   Берите ту, где в адресе есть **`-pooler`**.

> Подойдёт не только Neon: Vercel Postgres, Supabase или свой сервер — код
> обычный PostgreSQL.

**Строка подключения — это пароль от всей переписки.** Не выкладывайте её в
чаты, скриншоты и репозиторий.

---

## Шаг 2. Создать таблицы

Самый простой способ — прямо в браузере, ничего не устанавливая:

1. В консоли Neon откройте **SQL Editor**.
2. Откройте файл `db/schema.sql` из этого архива, скопируйте **всё**
   содержимое и вставьте в редактор.
3. Нажмите **Run**.

Должно появиться 12 таблиц: `users`, `sessions`, `conversations`,
`conversation_members`, `messages`, `files`, `message_attachments`,
`reactions`, `events`, `typing_state`, `invites`, `rate_limits`.

Проверить можно запросом:

```sql
SELECT table_name FROM information_schema.tables
WHERE table_schema = 'public' ORDER BY table_name;
```

Скрипт безопасно запускать повторно: он ничего не удаляет и не ломает уже
существующие данные.

> Жёлтые сообщения вида `NOTICE: column "grade" ... already exists, skipping` —
> это нормально, а не ошибка. Так скрипт сообщает, что часть уже на месте и он
> её пропускает. Плохо, только если написано **ERROR**.

<details>
<summary>Если удобнее из командной строки (нужен Node.js 20+)</summary>

```bash
npm install
DATABASE_URL="ваша-строка-подключения" npm run db:push
```
</details>

---

## Шаг 3. Выложить сайт

1. Зайдите на [vercel.com](https://vercel.com), нажмите **Add New → Project**.
2. Загрузите этот архив (или подключите репозиторий с GitHub).
   Next.js определится сам — настройки сборки менять не нужно.
3. В разделе **Environment Variables** добавьте две обязательные переменные:

   | Имя | Значение |
   |---|---|
   | `DATABASE_URL` | строка подключения из шага 1 |
   | `AUTH_SECRET` | случайная строка не короче 32 символов |

   `AUTH_SECRET` придумайте сами или возьмите из
   [random.org](https://www.random.org/strings/?num=4&len=20&digits=on&upperalpha=on&loweralpha=on&format=html)
   — просто склейте несколько строк. Он подписывает сессии: если его сменить,
   всех разлогинит.

4. Нажмите **Deploy** и подождите пару минут.

---

## Шаг 4. Первый вход

Откройте выданный адрес и **зарегистрируйтесь первым** — этот аккаунт получит
права администратора. Сделайте это сразу, до того как адрес разойдётся по
школе.

Дальше можно раздавать адрес: одноклассники регистрируются сами (логин, пароль,
класс), создают группы и заходят в них по коду.

---

## Необязательные настройки

Добавляются там же, в Environment Variables:

| Переменная | Зачем |
|---|---|
| `INVITE_ONLY` | `true` — закрыть регистрацию, пускать только по коду-приглашению |
| `ADMIN_USERNAME` | выдать права администратора конкретному логину при регистрации |
| `REGISTRATION_LIMIT` | сколько регистраций в час с одного адреса (по умолчанию 60) |

Коды-приглашений при `INVITE_ONLY=true` заводятся в SQL Editor:

```sql
INSERT INTO invites (code, max_uses) VALUES ('ГИМНАЗИЯ-2026', 30);
```

Название гимназии, список классов и длина кодов групп лежат в
`src/lib/config.ts`.

---

## Если что-то пошло не так

**«Не задана переменная окружения DATABASE_URL»** — переменная не добавлена в
Vercel или добавлена после сборки. Добавьте и нажмите **Redeploy**.

**Сайт открывается, но при входе ошибка** — скорее всего не выполнен шаг 2,
таблиц в базе нет. Проверьте запросом выше.

**«Не задана переменная AUTH_SECRET»** — добавьте её и пересоберите.

**Сообщения приходят с задержкой в минуту** — так бывает, когда вкладка
свёрнута: браузер замедляет фоновые вкладки. Вернитесь в приложение, всё
подтянется сразу.

**Всех разлогинило** — сменился `AUTH_SECRET`. Верните прежнее значение или
попросите всех войти заново.
